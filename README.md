# Vendor Onboarding Desk (ASA case study, PS-2)

Open `index.html` in a browser, or serve this folder (GitHub Pages works as-is).

- **New submission**: load a prepared case, edit any field, or drop the vendor's PDFs into Documents.
- **Run with real PDFs**: fetches `samples/<case>/` and reads every document in the browser (pdf.js).
- **Live run**: 9 stages, each check visible, ending in Approved / Pending / Rejected with the vendor email and internal note.
- **Dashboard**: history, outcomes, stop reasons; open any past run.
- **How it works**: process map, rules, assumptions, demo runbook.

Note: "Run with real PDFs" needs the page to be served over http(s) (not opened as a local file), and pdf.js loads from jsDelivr.
